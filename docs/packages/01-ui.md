# Package 1: UI components (`src/ui`)

Presentational components only: no store, no routing logic. Export everything from
`src/ui/index.ts`. Match `docs/design/*.png`.

| Component | Props | Notes |
| --- | --- | --- |
| `CheckCircle` | `state: 'full'\|'min'\|'pending'`, `color: RoutineColor`, `label: string`, `onPress()` | 44 px button; visuals per "four states" |
| `ProgressRing` | `value: number` (0..1), `size`, `thickness`, `color?`, `children` | SVG or conic; `role="img"` + `aria-label` prop |
| `Card` | `children`, `className?` | `bg-surface rounded-card p-4` |
| `Button` | `variant: 'primary'\|'ghost'\|'danger'`, button props | min height 44 |
| `Sheet` | `open`, `onClose`, `title`, `children` | bottom sheet on phone, centred dialog >= 900 px; `<dialog>` element, focus trapped, Esc closes |
| `SegmentedControl` | `options: {value,label}[]`, `value`, `onChange` | as in routine-edit.png |
| `Switch` | `checked`, `onChange`, `label` | `role="switch"` |
| `DayDots` | `cells: CellState[]`, `color` | 8 px dots, used in Today rows |
| `HeatGrid` | `cells: CellState[]`, `color`, `cellSize?` | 7 rows, column flow, as in progress.png |
| `TabBar` / `Sidebar` | `items: {to,label,icon}[]` | `NavLink`s; TabBar under 900 px, Sidebar above |
| `PageHeader` | `eyebrow`, `title`, `right?` | date + large title row |

`type CellState = 'full' | 'min' | 'pending' | 'empty'` (define and export it here).

Icons: inline stroke SVG (24 px, 1.8 stroke), never emoji. Add `src/ui/icons.tsx`.

Done when: every component renders in a simple `src/ui/Gallery.tsx` page (not
routed), typecheck and build pass, and each interactive component is keyboard usable.
