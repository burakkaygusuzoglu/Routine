# Package 12: Independent QA

You did not write this code. Check it like a careful tester.

1. Read CLAUDE.md, docs/ARCHITECTURE.md, docs/DESIGN.md and briefs 08-11.
2. `npm run typecheck`, `npm test`, `npm run build` must pass.
3. Build a local-only copy (`npx vite build --mode e2e --outDir dist-e2e`), serve it
   (`npx vite preview --outDir dist-e2e --port 4190`) and drive it with Playwright
   (Python, Chromium at /usr/bin/google-chrome, `service_workers='block'`) at
   390x844 with touch and an iPhone user agent, plus 375x667 and 1280x900.
4. Walk every flow in briefs 08-11 and the older ones: tick / undo / action sheet,
   timeline view, never-miss-twice (seed yesterday's data through the UI or by
   setting the clock with `page.clock`), celebration, focus session start to save,
   night mode fields persist, weekly page and garden, identity votes, icon picker,
   settings edit, backup round-trip, reload persistence.
5. Audit each screen: no horizontal overflow, every control >= 44x44, inputs >= 16px
   font, no text under 11px, no console errors.
6. Fix only clear, small bugs yourself (commit each fix separately with a clear
   subject, no attribution trailer). For anything bigger, describe it.
7. Save screenshots to /tmp/qa/.

Report: a pass/fail table per flow, bugs fixed (commit subjects), bugs left open,
and the screenshot paths.
